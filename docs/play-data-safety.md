# Play 콘솔 「데이터 안전」 설문 작성 가이드

Nursing XR v1.2.12 (`com.nursingxr.med_vocab`) 기준.
`nursingxr/med-vocab` 저장소의 앱 코드를 읽고 작성했습니다.
개인정보처리방침(`index.html`)과 이 설문의 답변은 **서로 어긋나면 안 됩니다** — Google은 둘을 대조합니다.

---

## 0. 전제 — 공통 답변

| 질문 | 답변 |
|---|---|
| 앱이 사용자 데이터를 수집 또는 공유합니까? | **예** |
| 전송 중 데이터가 암호화됩니까? | **예** (HTTPS/TLS, `lib/core/api_client.dart`) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** (이메일 요청 — 방침 제9조) |
| 앱에 광고가 포함됩니까? | **아니요** |
| 제3자 광고·분석 SDK를 사용합니까? | **아니요** (`pubspec.yaml`에 해당 패키지 없음) |
| Play Families 정책 대상입니까? | **아니요** (고등교육기관 학생·교수자 대상) |

아래 표의 **"수집"** = 앱이 기기 밖 서버로 전송함, **"공유"** = 제3자에게 전달함.

## 5. 자주 지적받는 부분

1. **서버 접속 로그의 IP 주소**
   Play 데이터 안전 설문은 *앱이 수집하는* 데이터를 묻습니다. 서버가 운영 목적으로 자동 기록하는
   접속 로그는 일반적으로 설문 신고 대상이 아니지만, 방침 본문에는 투명성을 위해 명시했습니다
   (제2-2조·제5조). 설문에서는 별도 항목을 체크하지 않아도 됩니다.

2. **"공유" 를 아니요로 답하고 싶은 유혹**
   교수자 열람 기능이 실재하므로 **아니요로 답하면 허위 신고**가 됩니다. 예로 답하고
   목적을 "앱 기능"으로 두면 심사에 문제되지 않습니다.

3. **계정 삭제 URL 미등록**
   계정 생성이 가능한 앱은 계정 삭제 요청 URL 등록이 필수입니다. `README.md` 4번 항목 참고.

4. **AI 해설 기능**
   앱이 서버로 보내는 것은 용어 ID뿐이고 사용자 입력 텍스트는 전송되지 않습니다
   (`game_api.dart` `getAiExplanation(termId)`). 따라서 생성형 AI 관련 추가 신고 사유는 없습니다.
   다만 백엔드가 프롬프트에 사용자 정보를 덧붙이지 않는지 `mt-app` 저장소에서 한 번 확인하세요.
